# LeLab Tutorials

A hands-on course for **LeLab** — the browser interface for [LeRobot](https://github.com/huggingface/lerobot). Seven pages, from installing LeLab to running a trained policy on an SO-101 arm.

## The seven pages

| # | Page | What you do |
|:--:|---|---|
| 1 | [Overview](en/01-overview.md) | What LeLab is, what you can do with it, what you need |
| 2 | [Install and run](en/02-install.md) | Install LeLab and open it in your browser |
| 3 | [Connect and calibrate](en/03-calibration.md) | Plug in the arms, pick the serial ports, calibrate |
| 4 | [Teleoperation](en/04-teleoperation.md) | Move the leader arm, watch the follower mirror it |
| 5 | [Record a dataset](en/05-record-dataset.md) | Capture episodes, with cameras |
| 6 | [Train and run inference](en/06-train-and-inference.md) | Train a policy, then execute it on the arm |
| 7 | [Troubleshooting](en/07-troubleshooting.md) | The problems people actually hit |

Read them in order the first time. Pages 3 to 6 follow the same order as the tabs in the app.
